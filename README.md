# MT6897 LJ9 kernel build

GitHub Actions workflow that builds the TECNO POVA 7 Ultra 5G (LJ9, MT6897) Android 15 kernel 6.1
and its MediaTek vendor modules from the official TECNO open-source release.

- kernel/ + vendor/: [TECNO_MTK_kernel_modules @ android15_kernel_modules_and_devicetree_mt6897](https://github.com/isus203/TECNO_MTK_kernel_modules/tree/android15_kernel_modules_and_devicetree_mt6897)
- kernel-6.1: [android_kernel_tecno_LJ9_mt6897 @ Android-15](https://github.com/isus203/android_kernel_tecno_LJ9_mt6897/tree/Android-15)

Run it from **Actions → Build MT6897 LJ9 kernel and modules → Run workflow**.
